# Delux Hand Car Wash

Conceptwebsite voor Delux Hand Car Wash in Sint-Truiden.

De site staat in `dist/index.html` en is bewust statisch gehouden zodat hij makkelijk kan worden aangepast in Visual Studio Code.

## Nog te bevestigen

- Definitieve openingsuren
- Prijzen en waspakketten
- Eigen foto's en eventueel logo
- E-mailadres, betaalmogelijkheden en afspraakbeleid
- Of GURAYA BV effectief de juridische entiteit achter Delux Hand Car Wash is
